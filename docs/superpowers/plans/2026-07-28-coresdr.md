# CoreSDR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A dependency-free Swift package that discovers an RTL-SDR (RTL2832U + R820T2) over USB and exposes tuning, gain, sample-rate control, and a live async IQ sample stream.

**Architecture:** Three layers. A `USBTransport` protocol is the only seam between pure driver logic and Apple's USB stack. The RTL2832U + R820T2 driver is pure logic over that protocol, so it is TDD'd end-to-end against a `MockUSBTransport` with no hardware. The concrete `IOUSBHostTransport` (real hardware) is quarantined to one file and validated by opt-in integration tests. A public `SDRDevice` actor wraps the driver.

**Tech Stack:** Swift 6, Swift Package Manager, Swift Testing (`import Testing`), `IOUSBHost`, `Accelerate`/`vDSP`. No third-party dependencies.

## Global Constraints

- **No third-party dependencies.** Apple system frameworks only. Never link or vendor `librtlsdr`/`libusb`. (A read-only reference copy of librtlsdr may exist under the scratchpad for transcription only; it is not a dependency and must not be referenced by package code.)
- **Deployment target: macOS 14+.** Set in `Package.swift`. Developed/tested on macOS 26.
- **Swift 6 strict concurrency**, swift-tools-version 6.0. All public types `Sendable`. Zero concurrency warnings.
- **Receive only.** No transmit paths.
- **Target device only:** RTL2832U demodulator + R820T2 tuner, USB VID:PID `0x0bda:0x2838`, bulk IN endpoint `0x81`, interface 0.
- **TDD.** Write the failing test first for every behavior that can be tested without hardware. Commit after each green step.
- **Reference source of truth for register values:** librtlsdr `src/librtlsdr.c` and `src/tuner_r82xx.c` (https://github.com/librtlsdr/librtlsdr). Exact sequences needed by this plan are inlined in the relevant tasks.

## Reference constants (used across tasks — transcribed from librtlsdr)

USB control-transfer encoding (`bRequest` is always `0`):

| Operation | `bmRequestType` | `wValue` | `wIndex` |
|---|---|---|---|
| Read RTL register block | `0xC0` | `addr` | `block << 8` |
| Write RTL register block | `0x40` | `addr` | `(block << 8) \| 0x10` |
| Read demod register | `0xC0` | `(addr << 8) \| 0x20` | `page` |
| Write demod register | `0x40` | `(addr << 8) \| 0x20` | `0x10 \| page` |

Blocks: `DEMODB=0, USBB=1, SYSB=2, TUNB=3, ROMB=4, IRB=5, IICB=6`.
USB regs: `USB_SYSCTL=0x2000, USB_EPA_CTL=0x2148, USB_EPA_MAXPKT=0x2158`.
SYS regs: `DEMOD_CTL=0x3000, DEMOD_CTL_1=0x300b`.
Multi-byte register values are big-endian in the payload (`data[0]=val>>8, data[1]=val&0xff`); 1-byte values send `val&0xff`.
RTL crystal: `28_800_000` Hz. R820T2 I2C address: `0x34` (7-bit `0x1a`; librtlsdr uses `0x34` as the write address on the IICB block). R820T2 register shadow starts at reg `0x05`, 27 registers (`0x05`–`0x1f`).

```swift
enum RTLBlock: UInt8 { case demod = 0, usb = 1, sys = 2, tuner = 3, rom = 4, ir = 5, i2c = 6 }

enum RTLRegisters {
    static func writeRequest(block: RTLBlock, addr: UInt16) -> USBControlRequest {
        USBControlRequest(requestType: 0x40, request: 0, value: addr, index: (UInt16(block.rawValue) << 8) | 0x10)
    }
    static func readRequest(block: RTLBlock, addr: UInt16) -> USBControlRequest {
        USBControlRequest(requestType: 0xC0, request: 0, value: addr, index: UInt16(block.rawValue) << 8)
    }
    static func demodWriteRequest(page: UInt8, addr: UInt16) -> USBControlRequest {
        USBControlRequest(requestType: 0x40, request: 0, value: (addr << 8) | 0x20, index: 0x10 | UInt16(page))
    }
    static func demodReadRequest(page: UInt8, addr: UInt16) -> USBControlRequest {
        USBControlRequest(requestType: 0xC0, request: 0, value: (addr << 8) | 0x20, index: UInt16(page))
    }
    static func payload(value: UInt16, length: Int) -> [UInt8] {
        length == 1 ? [UInt8(value & 0xff)] : [UInt8(value >> 8), UInt8(value & 0xff)]
    }
}
```

### Task 9: RTL2832U baseband init sequence

**Files:**
- Modify: `Sources/CoreSDR/Driver/RTL2832U.swift`
- Test: `Tests/CoreSDRTests/RTL2832UInitTests.swift`

**Interfaces:**
- Produces: `func initBaseband() async throws` on `RTL2832U`.

The exact sequence (from `rtlsdr_init_baseband`), where `W(b,a,v,len)` = block-register write and `D(page,addr,v,len)` = demod write:

```
W(usb, 0x2000, 0x09, 1)          // USB_SYSCTL
W(usb, 0x2158, 0x0002, 2)        // USB_EPA_MAXPKT
W(usb, 0x2148, 0x1002, 2)        // USB_EPA_CTL
W(sys, 0x300b, 0x22, 1)          // DEMOD_CTL_1
W(sys, 0x3000, 0xe8, 1)          // DEMOD_CTL
D(1, 0x01, 0x14, 1)              // soft reset on
D(1, 0x01, 0x10, 1)              // soft reset off
D(1, 0x15, 0x00, 1)
D(1, 0x16, 0x0000, 2)
D(1, 0x16, 0x00, 1) ... D(1, 0x1b, 0x00, 1)   // loop i=0..5: addr 0x16+i, 1 byte
// FIR filter: 20 bytes to demod page 1, addr 0x1c+i (see fir encoding below)
D(0, 0x19, 0x05, 1)
D(1, 0x93, 0xf0, 1)
D(1, 0x94, 0x0f, 1)
D(1, 0x11, 0x00, 1)
D(1, 0x04, 0x00, 1)
D(0, 0x61, 0x60, 1)
D(0, 0x06, 0x80, 1)
D(1, 0xb1, 0x1b, 1)
D(0, 0x0d, 0x83, 1)
```

FIR default coefficients (from `fir_default`): 8-bit signed `[-54,-36,-41,-40,-32,-14,14,53]` then 12-bit signed `[101,156,215,273,327,372,404,421]`, packed into 20 bytes by `rtlsdr_set_fir`:
- Bytes 0–7: the eight 8-bit values as-is (two's complement `UInt8`).
- Bytes 8–19: pack pairs of 12-bit values `(v0,v1)` per group as `[v0>>4, (v0<<4)|((v1>>8)&0x0f), v1]`.
Compute the 20 bytes: `[0xca,0xdc,0xd7,0xd8,0xe0,0xf2,0x0e,0x35,0x06,0x50,0x9c,0x0d,0x71,0x11,0x14,0x71,0x74,0x19,0x41,0xa5]`. Each byte is written with `D(1, 0x1c + i, byte, 1)`.

- [ ] **Step 1: Write failing test asserting the full recorded sequence**

```swift

    let m = MockUSBTransport()
```
